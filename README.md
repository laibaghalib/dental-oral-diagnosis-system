# Dental and Oral Diagnosis System

AI-powered dental image analysis with explainable Grad-CAM heatmaps. Built with Flask and an ensemble of deep learning models (ResNet18, DenseNet121, EfficientNetV2).

## Demo

https://github.com/user-attachments/assets/5a1b020e-c3c3-48e8-bb52-bc258f188178

## Features

- User registration and login
- Dental image upload and AI-based analysis
- Explainable AI heatmaps (Grad-CAM)
- Scan history and PDF report generation
- User feedback and settings

## Tech Stack

Python, Flask, TensorFlow/Keras, SQLAlchemy, OpenCV

## Note

Model weight files (.h5) are not included in this repository because of their size.
